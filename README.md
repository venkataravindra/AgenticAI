## 🚦 Getting Started

### Prerequisites
```bash
# Clone the repository
git clone https://github.com/venkataravindra/AgenticAI.git

# Create virtual environment
python -m venv venv

# Activate (Windows)
venv\Scripts\activate

# Activate (Mac/Linux)
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### Run Examples
```bash
# Python basics
cd Python/basics && python hello_world.py

# Machine Learning example
cd Machine_Learning/supervised && python linear_regression.py

# Start FastAPI server
cd FastAPI && uvicorn main:app --reload
```
